# AniMotion Studio 0.4 — Motion Lab / Low VRAM Edition

Бесплатная локальная студия для подготовки анимационных сцен и YouTube-вставок. В версии 0.4 появился **Motion Lab**: сборка ролика из твоих изображений с движением камеры, переходами и титрами. Motion Lab работает в браузере и не запускает тяжёлые AI-модели.

> Профиль компьютера: NVIDIA GeForce RTX 2050, 4 ГБ выделенной видеопамяти. Поэтому первым рабочим инструментом выбрана лёгкая анимация изображений, а не text-to-video диффузия.

## Открыть AniMotion в интернете

После первого включения GitHub Pages приложение будет доступно по адресу:

https://paulrodo.github.io/animotion-studio/

Чтобы включить публикацию один раз: открой Settings → Pages → Build and deployment → Source и выбери **GitHub Actions**. Затем открой Actions и дождись успешного задания **Deploy AniMotion Studio to GitHub Pages**. Последующие изменения `index.html` будут публиковаться автоматически.

Онлайн-версия предназначена для браузерного Motion Lab (сборка WebM из изображений). Вкладка ComfyUI/ИИ не может обратиться к прокси на твоём компьютере через GitHub Pages; для этого скачай ZIP и запусти `start-animotion.bat`.

## Как открыть AniMotion на Windows

1. Открой репозиторий https://github.com/PaulRodo/animotion-studio.
2. Нажми зелёную кнопку **Code** → **Download ZIP**.
3. Найди скачанный ZIP в папке «Загрузки», нажми правой кнопкой → «Извлечь всё».
4. Открой распакованную папку `animotion-studio`.
5. Дважды щёлкни `start-animotion.bat`. Если Windows спросит разрешение, запускай только файл из своего репозитория.
6. Браузер откроет **http://127.0.0.1:8090**. Оставь чёрное окно сервера открытым, пока пользуешься приложением.
7. Для завершения работы вернись в чёрное окно и нажми `Ctrl+C`.

**Нужно один раз установить Python 3.10 или новее** с https://www.python.org/downloads/ и во время установки включить `Add Python to PATH`.

### Запуск только браузерной версии

Если двойной щелчок по `index.html` открывает его как текст, используй `open-in-browser.bat`. Он ищет установленный Edge или Chrome и открывает HTML именно в браузере. Также можно нажать правой кнопкой на `index.html` → «Открыть с помощью» → Microsoft Edge или Google Chrome. В браузерном режиме ComfyUI-интеграция не работает; для неё нужен `start-animotion.bat`.

> Репозиторий оставляем Private. GitHub хранит исходный код, а не запускает приложение на твоём компьютере. На GitHub Free Pages нельзя публиковать сайт из приватного репозитория; для этого пришлось бы открыть репозиторий, чего мы делать не будем. См. [официальные ограничения GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages).

## Что нового в Motion Lab 0.4

1. Добавление нескольких картинок PNG, JPG и WEBP.
2. Изменение порядка кадров на таймлайне.
3. Для каждого кадра можно выбрать движение: плавный наезд, отдаление, панорама влево/вправо/вверх, лёгкое движение или почти статичный кадр.
4. Длительность кадра 3–10 секунд.
5. Настройка формата 16:9, 9:16 или 1:1; 24, 30 или 60 FPS.
6. Плавные переходы между изображениями.
7. Заголовок и подпись поверх видеоряда.
8. Предпросмотр и запись готового ролика в **WebM** прямо браузером.

Экспорт WebM требует современный Chrome или Edge с поддержкой `MediaRecorder`. Аудиодорожка пока не добавляется. После экспорта можно импортировать WebM в видеоредактор или загрузить ролик на YouTube. Motion Lab не требует RTX или нейросети.

**Важно:** исходные изображения в Motion Lab хранятся только в памяти открытой вкладки; после перезагрузки их надо добавить заново. Сохраняй изображения отдельно. Обычные сцены и персонажи редактора хранятся в localStorage текущего браузера. Экспортируй JSON-проект для резервной копии.

## Следующие AI-эксперименты на RTX 2050 4 ГБ

Не начинай с Wan 2.2, Stable Video Diffusion, SDXL или больших AnimateDiff workflow — они могут не поместиться в 4 ГБ видеопамяти.

- Stable Diffusion 1.5 — отдельный тест для генерации неподвижных изображений; начни с 384×384, batch 1 и low-VRAM/offloading, если поддерживается. Успех и скорость не гарантируются.
- LivePortrait — кандидат для переноса мимики/движения с driving-видео на портрет; это не text-to-video и не анимация любых объектов. Потребление VRAM проверим коротким тестом.

Ссылки: [ComfyUI](https://github.com/Comfy-Org/ComfyUI) · [LivePortrait](https://github.com/KwaiVGI/LivePortrait).

## Подключение ComfyUI (опционально)

1. Запусти ComfyUI локально на http://127.0.0.1:8188.
2. Запусти AniMotion через `start-animotion.bat` и перейди на вкладку «ИИ-генерация».
3. Оставь адрес `/comfy` и нажми «Проверить подключение».
4. Загрузи совместимый API-workflow. В ComfyUI нужен Dev Mode → File → Export Workflow (API); обычный визуальный workflow JSON не подходит.
5. Выбери позитивный и при необходимости негативный текстовый узел.

Не открывай порты 8090 или 8188 в интернет и не загружай workflow из неизвестных источников.

## Структура проекта

- `index.html` — интерфейс Studio, storyboard, characters, AI-подключение и Motion Lab.
- `run_server.py` — локальный веб-сервер и прокси ComfyUI, слушает только 127.0.0.1.
- `start-animotion.bat` — запуск на Windows.
- `CHECK-GPU.bat` — диагностика видеокарты NVIDIA.
- `docs/HARDWARE.md` — рекомендации по RTX 2050 4 ГБ.
- `tests/` и `.github/workflows/ci.yml` — автоматические проверки.
