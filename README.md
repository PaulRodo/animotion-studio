# AniMotion Studio 0.6 — AI Scene Pipeline

AniMotion Studio — редактор и конвейер подготовки AI-анимации для YouTube. Главный режим теперь строит последовательность планов из одного текстового описания и отправляет каждый план в подключённый workflow ComfyUI. Программа показывает именно те видео, GIF или изображения, которые вернула модель.

**Важное различие:** AniMotion не содержит собственной большой видеомодели и не обещает бесплатное неограниченное text-to-video. Для реальной генерации нужна установленная локальная модель ComfyUI или внешний провайдер. Планировщик помогает режиссёрски разложить текст на планы, сохранить описание героя и подготовить промпты; само видео создаёт подключённая нейросеть. Автоматической LLM-интерпретации текста внутри приложения пока нет.

## Открыть AniMotion

Публичная веб-версия: https://paulrodo.github.io/animotion-studio/

GitHub Pages размещает статические файлы браузерного приложения. Он **не может подключаться к ComfyUI на твоём компьютере**. Для локальной генерации скачай проект и запускай через локальный сервер, описанный ниже.

## Запуск на Windows

1. Открой https://github.com/PaulRodo/animotion-studio.
2. Нажми зелёную кнопку **Code** → **Download ZIP**.
3. В папке «Загрузки» распакуй ZIP через «Извлечь всё».
4. Открой распакованную папку `animotion-studio`.
5. Дважды щёлкни `start-animotion.bat`.
6. Браузер откроет http://127.0.0.1:8090. Оставь чёрное окно сервера открытым.
7. Для завершения работы нажми `Ctrl+C` в чёрном окне.

Для первого запуска требуется Python 3.10 или новее: https://www.python.org/downloads/ . Во время установки включи **Add Python to PATH**.

Можно открыть `index.html` в Edge/Chrome напрямую через `open-in-browser.bat`, но в этом режиме локальный прокси ComfyUI не работает.

## Основной рабочий процесс — генератор AI-сцен

1. На главном экране напиши, что должно происходить в видео.
2. Добавь точное описание внешности, одежды и постоянных особенностей персонажа. Этот текст повторяется во всех планах.
3. Выбери стиль: Mixed, реализм, 3D, 2D, аниме или Motion Graphics. По умолчанию установлен Mixed.
4. Выбери количество планов, формат, длительность, движение камеры, характер движения и свет.
5. Нажми **Сформировать планы**. AniMotion создаст постановочные варианты (общий, средний, крупный и т. д.). Каждый промпт можно отредактировать.
6. Запусти ComfyUI на http://127.0.0.1:8188.
7. В генераторе оставь адрес `/comfy`, проверь соединение и загрузи API-workflow через **Dev Mode → File → Export (API)**.
8. Выбери позитивный текстовый узел и, если он есть, негативный узел. Нажми **Сгенерировать все планы**.
9. AniMotion отправляет планы последовательно и показывает реальный результат каждого задания.

Workflow может генерировать видео, GIF или только изображения. Если модель вернула изображения, приложение так и сообщит: для движения нужен Text-to-Video или Image-to-Video workflow. Отдельные клипы пока не склеиваются автоматически в один финальный фильм — их можно скачать и собрать в видеоредакторе.

Планы используют общую историю и повторяемое описание персонажа, но генеративные модели не гарантируют идеальную идентичность лица, одежды или деталей между разными клипами. Проверяй результаты и при необходимости уточняй промпты.

## Реальные ограничения оборудования

Известный профиль компьютера: NVIDIA GeForce RTX 2050, 4 ГБ выделенной VRAM и около 16 ГБ системной RAM. Общая/разделяемая память Windows не равна выделенной видеопамяти.

Современные модели text-to-video требуют намного больше ресурсов. Например, документация LTX для ComfyUI указывает 32 ГБ VRAM; руководство NVIDIA по продвинутому генеративному видеоконвейеру указывает минимум 16 ГБ VRAM и рекомендует 64 ГБ RAM. Поэтому локальный запуск полноценного видеогенератора на RTX 2050 4 ГБ малореалистичен и может завершиться ошибкой нехватки памяти.

Для этой видеокарты разумнее начинать с небольших text-to-image workflow (batch 1, малое разрешение, offloading — если модель это поддерживает) и коротких тестов. Это не означает, что любая модель SD 1.5 гарантированно запустится: проверяй фактическое использование памяти.

### Облачные генераторы и бесплатный доступ

AniMotion не встроен в конкретный облачный видеосервис. Облачная генерация требует поддерживаемого API, аккаунта и обычно кредитов/оплаты. Не существует гарантированного неограниченного бесплатного API для высококачественного text-to-video. Например, документация Hugging Face сейчас указывает $0.10 ежемесячных кредитов для бесплатных аккаунтов на Inference Providers; эти кредиты могут изменяться и не являются бесплатным видеотарифом.

Источники:
- LTX + ComfyUI: https://docs.ltx.io/open-source-model/integration-tools/comfy-ui
- Руководство NVIDIA по AI-видео и требованиям: https://www.nvidia.com/en-us/geforce/news/rtx-ai-video-generation-guide/
- Требования NVIDIA ComfyUI: https://build.nvidia.com/playbooks/video-gen-guide
- Hugging Face Inference Providers: https://huggingface.co/docs/inference-providers/pricing

## Дополнительные инструменты

**Студия и раскадровка.** Редактирование сцен, промптов и персонажей, локальное сохранение проекта и экспорт JSON.

**Motion Lab.** Сборка ролика из нескольких изображений с движением камеры, переходами, титрами и экспортом WebM. Это монтаж из изображений, а не text-to-video. Файлы изображений остаются в памяти текущей вкладки; сохрани исходники отдельно.

**Графическое демо.** Процедурные графические эффекты браузера для заставок и быстрых тестов. Это не нейросеть и не генерация произвольных персонажей.

## Безопасность

Локальный сервер и прокси ComfyUI слушают только `127.0.0.1`. Не открывай порты 8090 или 8188 в интернет. Не загружай неизвестные workflow и не сохраняй API-ключи, пароли, личные ролики или веса моделей в репозитории. Репозиторий сейчас публичный — исходный код может прочитать любой пользователь GitHub.

## Файлы проекта

- `index.html` — генератор AI-сцен, Studio, storyboard, персонажи, Motion Lab и графическое демо.
- `run_server.py` — локальный веб-сервер и loopback-прокси ComfyUI.
- `start-animotion.bat` — запуск на Windows.
- `CHECK-GPU.bat` — диагностика видеокарты.
- `docs/HARDWARE.md` — профиль RTX 2050 и рекомендации.
- `tests/` и `.github/workflows/ci.yml` — автоматические проверки.
